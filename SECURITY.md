# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this framework or any of the included agent skills, please send an email to the repository owner or open a confidential security advisory via GitHub.

We adhere strictly to responsible disclosure:
- **Triage SLA:** We acknowledge all security reports within 72 hours.
- **Remediation SLA:** Critical vulnerabilities are prioritized and patched within 24-48 hours.
- Please do NOT disclose vulnerabilities publicly until a patch has been released.
